# Public source snapshot

This independent draft project was extracted on 2026-10-17 and sanitized for
publication. Personal paths, league and manager identities, private session
identifiers, and personal commit metadata are not part of the public snapshot.
Browser screenshots containing private league context are omitted.

Research data retains its public player statistics and numerical outcomes;
identifying labels in examples and captured evidence have been anonymized.
The research artifact manifest describes the sanitized files.

Private configuration, runtime state, and recovery backups remain local and
are excluded from Git and ZIP downloads. See [privacy notes](PUBLIC_RELEASE_PRIVACY.md).
